**Assumptions (not given by the book)**
- Load by band: at each depth the 200 plf is shared by the sheathed bands in proportion to their length. A-B: band 1-2 gets 200(25/125) = 40 plf, band 2-4 gets 200(100/125) = 160 plf. B-C: band 2-4 only, 200 plf. Each band is a simple beam across the depth between its own edges (1-2 spans A-B, 2-4 spans A-C). (Book method p4-p5; the tool must reproduce the band split to match the basic shears.)
- Distribution to offset wall lines (rule for the tool). Line B/C (SW1 on B, SW3 and SW4 on C) is one line of resistance. Effective span to A = wall-length-weighted average of the distance from A to each B/C wall: [8(35) + (8 + 15)(50)] / 31 = 46.1 ft. R_A = w(46.1)/2 = 4612 lb, R_B/C = wL - R_A = 5388 lb. Only the B/C walls are weighted; SW2 is not. (Book p14 recommends this over its 400 lb trial shift (p12-p13). The equal split wL/2 (first run) fails closure.)
- Within a wall line, the line force is split to walls in proportion to wall length (SDPWS 4.3.5.5.1 exception), including across the offset (SW1 on B shares with SW3 and SW4 on C). (Book p4.)
- The corrected run (Fig 3.21) uses R_A = 4600, R_B/C = 5400 (400 lb trial shift). Member forces in `expected` carry tolerances that cover R_A from about 4580 (exact closure, derived) to 4612 (weighted-average rule). (Book shows no corrected run for the 4612/5388 split; it calls it close enough.)
- Wall line name "B/C" groups SW1, SW3 and SW4. (Book treats them as one line (p1-p3).)
- Sign convention: the "+" element in this example (top face +x, bottom -x, left face -y, right face +y) is the mirror of the Ex 4.1 element. Printed signs already follow it, so no conversion is applied. (FORMAT.md: book sign per the figure element. A tool using the Ex 4.1 element must negate every unit shear in this file.)
- Values in the corrected run that the book does not print (wall forces, TD reactions, TD and net shears inside TD1) are not recorded. (Book shows only reactions and the Fig 3.21 member forces for that run.)
