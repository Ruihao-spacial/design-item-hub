# Diaphragm to LRS — verification cases

Generated by `npm run dlrs:cases:doc` from `tests/dlrs-cases/*.json` (sources with the hand-calc arithmetic: `tests/dlrs-cases/src/`). Engine: calc v2.

**What is verified.** Each case is a small model with a hand calc. The hand calcs use the published closed forms (AISC Steel Construction Manual Table 3-23: Case 1, 4, 8, 24, 25, 26 and their general overhang form), not the engine's lever rule, so they check the engine independently. D01 is the team's spreadsheet (reference page C.6): its expected values are the spreadsheet's own numbers.

**Engine.** Every uniform part is cut at the two supports into pieces; every piece and point load gives R1 = W·(x₂ − x̄)/l and R2 = W·(x̄ − x₁)/l (l = x₂ − x₁). A load on an overhang gives a negative value at the far support (the reaction reverses).

**Checks D1–D9** run on every item: D1 ΣR = ΣW + ΣP per diaphragm · D2 Σ reactions to lines = F_x + Σ manual P per level · D3 geometry / supports · D4 no loops · D5 split = 100 % · D6 every line has a place to go below · D7 ΣV = ΣF at and above − resisted above · D8 F_x and area present · D9 each line in at most one merge per level.

**How to review a case:** read the intent and the model, follow the hand calc, then compare *Expected* with *Calculated*. The same case is in the local project **DLRS Verification** (`npm run dlrs:seed`) — open it and use the **Verification** tab. Forces in kip; tolerance ± 0.0005 k unless stated.
